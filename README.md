# Micro-IoT ecosystem

Екосистема для збору, передавання та перегляду телеметрії з пристроїв і BMS-модулів.

Компоненти розділені на окремі репозиторії: їх можна розробляти, запускати й використовувати незалежно. Цей репозиторій — навігаційна сторінка з описом проєкту та посиланнями на його частини.

> Проєкт розвивається. Склад компонентів, їхній статус і спосіб взаємодії можуть змінюватися.

## Компоненти

| Компонент | Призначення | Статус |
|---|---|---|
| [Micro-IoT-Cloud](https://github.com/lagidnyj/Micro-IoT-Cloud) | Хмарна частина: API для JSON-телеметрії, адмінка, розділені користувачі та токени доступу. | Опублікований |
| ESP32 Daly BMS Monitor | Модуль для читання даних з Daly BMS за допомогою ESP32. | В роботі |
| Arduino JK BMS модуль | Модуль для читання даних з JK BMS за допомогою Arduino. | в роботі |
| Android APK | Мобільний застосунок для перегляду або роботи з даними екосистеми. | Готовий, але ще не опублікований |
| Вебпанель / UI | Окремий вебінтерфейс для перегляду телеметрії або керування системою. | Можливий окремий компонент, в розробці |

## Як компоненти пов’язані

Модулі для ESP32 та Arduino можуть збирати дані з BMS і передавати їх до хмарної частини. Хмара приймає телеметрію через API та надає засоби для роботи з користувачами й доступом.

Окремі інтерфейси — наприклад, Android-застосунок або вебпанель — можуть використовуватися для перегляду даних. Їхню фактичну взаємодію з API буде описано після узгодження та публікації компонентів.

```text
Daly BMS ── ESP32-модуль ─────┐
                              ├──> Micro-IoT-Cloud ──> Android-застосунок
JK BMS ─── Arduino-модуль ────┘                    └──> Вебпанель
```

*Схема попередня: її можна змінити відповідно до реалізації компонентів.*
